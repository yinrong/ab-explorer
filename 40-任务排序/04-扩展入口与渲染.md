# 04 · WebviewViewProvider + 渲染 + 扩展入口
**依赖谁**：02, 03

## 做什么
`src/provider.ts`（消息路由、FileSystemWatcher、状态持久化）、
`src/extension.ts`（activate、注册命令与菜单）、
`webview/main.ts`（DOM 渲染、溢出实测、事件绑定）、`webview/style.css`。

## 做完的判据
`npm run build` 通过；`code --install-extension` 后活动栏出现图标，打开目录能看到 A/B 两区。

## 理解
溢出判定必须用真实 DOM（`scrollHeight > clientHeight`），只能在 webview/main.ts 里做，
provider 只负责数据与消息转发。
